Método

SQL visible. Alcance controlado.

Un parser léxico reconoce indicador, periodo y operación dentro de un catálogo cerrado. El SQL sale de plantillas permitidas con parámetros enlazados y se ejecuta en SQLite abierto en mode=ro. Si hay un modelo configurado, solo puede devolver un plan JSON validado; si falla, se usa el parser local. Atlas es opcional y no participa en la consulta analítica.
