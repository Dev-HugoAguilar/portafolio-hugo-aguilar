# ORBITA — Paquete para el harness

1. Extraer el ZIP en una carpeta de trabajo fuera de la raíz pública del sitio.
2. Abrir el repositorio del portafolio en el harness y adjuntar esta carpeta.
3. Entregar `PROMPT_HARNESS.md` como instrucción.
4. Ejecutar `python scripts/verify_package.py` desde esta carpeta (Python 3, biblioteca estándar).
5. Revisar implementación con `ACCEPTANCE.md`.

Incluye ficha completa, datos estructurados, metadatos de fuentes, HTML funcional UI 26 y adaptador opcional React. No contiene el repositorio del portafolio: el harness debe descubrir su estructura. La ruta sugerida `dashboards/orbita/` es una ruta de asset; la URL editorial final depende del router existente.

El estado de publicación es pendiente. No hay backend que instalar ni claves. El HTML contiene dependencias y atribuciones ya incrustadas; no se asigna una licencia nueva a esos recursos ni al catálogo. Preservar avisos y verificar condiciones antes de redistribuir públicamente.
